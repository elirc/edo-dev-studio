# Local fonts

These are the exact Latin WOFF2 files used by the existing Google Fonts build, copied without modification. Keeping them in the repository removes the Google Fonts download from development and production builds. Both typefaces remain self-hosted and visually identical.

- Manrope: normal, variable weight 200–800. [Upstream license](https://github.com/google/fonts/blob/main/ofl/manrope/OFL.txt).
- Cormorant Garamond: normal and italic, variable fonts used at weights 400–600. [Upstream license](https://github.com/google/fonts/blob/main/ofl/cormorantgaramond/OFL.txt).

The copyright notices and SIL Open Font License 1.1 are included beside the fonts. These subsets cover the site's Italian text. Include appropriate additional subsets if adding languages that need other scripts.
